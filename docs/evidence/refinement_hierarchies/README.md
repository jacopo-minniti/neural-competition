# Refinement hierarchy evidence

This compact record retains the aggregate analysis, main figure, and executed
protocols for the natural (N=1,2,4) refinement hierarchy experiments. The
intermediate implementation-distribution theory developed alongside these runs
is not part of the maintained model.

- `summary.json`: aggregate natural-width and numerical-resolution results.
- `hierarchy_budget.png`: width, closure, recovery, and mastery figure.
- `protocols/`: configurations and hashes for the fresh, wider, and step-size
  runs.

Raw trajectories and checkpoints were removed after preservation commit
`92b7904`; rerun them with `scripts/studies/run_refinement_hierarchy.py`.
