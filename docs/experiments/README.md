# Experiment overview

| Evidence family | Main purpose | Current conclusion |
|---|---|---|
| Discrete contextual toys | Test loss of a later-needed refinement above sufficient capacity | Persistent narrow failures replicate; width changes dynamical survival, not only initial support |
| Continuous variation | Test acquisition and recovery beyond atomic prototypes | Some closed responses recover; permanent exhaustion is not general |
| Separate-attribute and frequency controls | Test whether the mechanism requires one semantic feature | It does not; parameter implementation overlap is what matters |
| Multiple refinements | Test decreasing-frequency hierarchies | Width reduces demanded closures and improves timely mastery; reopening alone is insufficient |
| MNIST local probes | Test teacher-free options on real images | Short local contrasts are predictable, but persistent competition and width mediation are weak |
