# Figures

Only maintained studies keep plots in the working tree. Tables remain the
source for exact values and uncertainty.

- `sign_survival/`: targeted sign protection and certified population error floors;
  see the [report](../reports/sign_survival.md) for scope and attribution limits.

- `feature_profile/`: fresh paired interventions and training trajectories;
  see the [report](../reports/feature_profile.md) for controls and limitations.
- `residual_growth/`: ordinary training, signed-role availability, 100k-step
  follow-up, and the failed sign-threshold prediction. Read the
  [report](../reports/residual_growth.md) before interpreting the panels.
- `mnist/`: training, matched metrics, cumulative budgets, finite-step controls,
  and full-objective probes. Read the [MNIST report](../reports/mnist.md).

Figures are PNGs; duplicate PDF exports and superseded historical plot galleries
were removed. The active analysis scripts regenerate these plots. Historical
plots remain recoverable from Git commit `b03c53f`.
