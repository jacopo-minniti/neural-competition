# Model guide

The [report](../../report.tex) introduces response, options, and competition.
The [protected-reserve chapter](competition_reserve.md) gives the mathematical
model and assumptions; [co-occurrence and parity](reserve_relaxation.md) describes
its controlled extensions. [Spectral options](spectral_options.md) gives
additional background on the underlying response measures.

Earlier alternative models and their supporting derivations are in
[the archive](../../archive/README.md).
