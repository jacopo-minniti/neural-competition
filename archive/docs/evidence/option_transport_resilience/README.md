# Delayed-demand and recovery evidence

The retained analysis files and figures cover fresh discrete and continuous toy
cohorts, matched-response interventions, delayed-demand timing controls, and
conservative recovery certificates.

Discrete narrow failures lose later-needed responses before refinement demand
dominates. Continuous variants demonstrate genuine recovery. Generic matched-
response preservation gives only weak discrete rescue and can harm continuous
learning. The recovery bound is valid but has limited empirical coverage.

Raw states and trajectories are archived at commit `92b7904`; maintained delayed-
demand scripts reproduce the collections.
