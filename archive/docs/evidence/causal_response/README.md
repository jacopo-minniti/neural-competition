# Finite-budget causal-response evidence

`analysis.json` contains the fresh broad cohort, focused replication, timing
controls, seed-bootstrap uncertainty, and individual pressure/preservation
contrasts. The retained figures show forecast accuracy and correction windows.

One midpoint gate refresh reduces broad-cohort prediction error from .237 to
.091 of a zero-effect baseline. Causal impairments are mostly immediate and
transient; the apparent persistent digit-specific effect fails to replicate.
Preservation often reduces drift while harming longer correction.

Raw checkpoints and branch outputs are archived at commit `92b7904`. Cohort
plans and case files remain here; maintained producer/analyzer scripts regenerate
the study.
