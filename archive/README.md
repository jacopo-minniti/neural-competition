# Earlier models and supporting evidence

This archive keeps prior research separate from the active protected-reserve
model. It contains earlier theory under `docs/model/`, compact experiment
records under `docs/evidence/`, exploratory code under `scripts/studies/`, and
historical tests and figures. See the preserved documentation for assumptions,
negative results and caveats; these models are not the current project focus.

Large `.npz` simulation arrays from the older power-law and probabilistic
competition studies were removed from the working tree, while summaries,
protocols, figures and source snapshots were retained. Those arrays were tracked
before cleanup and can be recovered from Git history at their former paths under
`docs/evidence/`. The archived source is preserved for reference; its original
paths and raw inputs may need restoration to rerun old pipelines. Deleted
ignored local runs were not tracked in Git. Git history itself has not been
rewritten.
