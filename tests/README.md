# Tests

The maintained suite checks:

- spectral and matrix-free response calculations;
- local bilinear response dynamics and physical gate readout;
- finite-budget causal interventions;
- delayed-demand recovery and matched-response constructions;
- heterogeneous toy response and recycling operations;
- exact pressure transport, Gaussian closing/opening laws, and functional null events;
- associated power-law task capacity, conditional sample-force moments, and
  arbitrary-state local forecasts;
- exact finite-update learning ledgers.

## Reserve checks

`test_competition_reserve.py` checks invariance and the protected response floor,
functional-progress inversion, analytic rare-gate lifetimes, joint functional
null events under the last-alternative law, and the three-unit
capacity witness on prototype and continuous 24–32-factor tasks.
